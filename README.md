# AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides useful feedback to improve them.

## Features

- Upload PDF or DOCX resumes
- Extract resume text automatically
- Detect technical skills
- Generate a resume score out of 100
- Provide AI-based resume recommendations
- Display extracted resume content
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- PyPDF2
- python-docx
